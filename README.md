# MIR-Laser-Control 项目总览

> 基于 STM32F103RCT6 的多激光器精密控制系统，支持三路激光器联动控制、温度门控保护、串口指令调节与实时反馈监测。

## 1. 项目简介

MIR-Laser-Control 是一个面向工程应用的嵌入式激光控制项目，核心目标是实现多激光器在安全约束下的稳定驱动与精细调节。项目重点解决了多设备联动、优先级互锁、反馈测量与安全启动等问题。

## 2. 仓库结构

本仓库包含两套主工程：

- `LaserCtrl_FreeRTOS-V1.1.1`：基于 FreeRTOS 的多任务版本（推荐主线）
- `LASERCTRL_ALL-1.1.1`：裸机轮询版本（便于理解控制逻辑与快速验证）

根目录文件：

- `README.md`：仓库基础说明
- 各子目录内 `README.md`：对应工程的详细说明

## 3. 核心功能

- 三路激光器独立调节（Laser1 / Laser2 / Laser3）
- 温度就绪门控与级联优先级保护（1 > 2 > 3）
- 双路径 DAC 输出：
  - Laser1/2：STM32 内部 DAC
  - Laser3：MCP4725 外部 I2C DAC
- ADC + DMA 实时采样反馈（电压/电流）
- UART 指令控制（`0`~`9`）与日志回传
- 安全启动：上电默认零输出、条件满足后逐级使能

## 4. 软件架构对比

### 4.1 FreeRTOS 版本（`LaserCtrl_FreeRTOS-V1.1.1`）

- 任务化设计：串口接收、指令处理、温度监控、ADC采样、日志发送等解耦
- 同步机制：队列、互斥锁、信号量、事件标志
- 特点：实时性更好、结构更清晰、扩展性更强

### 4.2 裸机版本（`LASERCTRL_ALL-1.1.1`）

- 主循环轮询执行温度检测、串口解析与输出控制
- 逻辑集中，便于学习与调试
- 特点：上手快，但在复杂场景下扩展性和并发能力弱于 RTOS 版本

## 5. 硬件与外设资源

- MCU：STM32F103RCT6
- 时钟：HSE 8MHz + PLL，系统主频 72MHz
- 通信：USART2（115200, 8N1）
- 外设：ADC1（4通道扫描）+ DMA1_CH1、DAC 双通道、I2C1（MCP4725）
- 温度检测输入：PB13 / PB14（Laser3 可按版本策略配置）
- 使能控制输出：PB12 / PA15 / PC4

## 6. 指令映射（UART）

- Laser1：`0` `1` `2` `3`
- Laser2：`4` `5` `6` `7`
- Laser3：`8` `9`

说明：各指令对应增减步进与饱和保护，具体步进参数可在 `freertos.c`（RTOS）或 `main.c`（裸机）中调整。

## 7. 编译与下载

## 7.1 开发环境

- Keil MDK-ARM（建议 V5.32 及以上）
- STM32CubeMX（用于 `.ioc` 配置维护）
- ST-Link / J-Link

## 7.2 构建步骤

1. 打开对应工程的 `MDK-ARM/*.uvprojx`
2. 确认芯片型号 `STM32F103RC`
3. 编译（F7）
4. 下载（F8）

## 8. 推荐使用方式

- 开发与扩展优先使用 `LaserCtrl_FreeRTOS-V1.1.1`
- 快速验证硬件链路可先用 `LASERCTRL_ALL-1.1.1`
- 发布前建议进行：
  - 温度门控边界测试
  - DAC 上下限与步进一致性测试
  - ADC 反馈标定与串口日志核对

## 9. 后续优化建议

- 增加统一参数配置头文件（步进、上限、标定系数）
- 增加异常状态码与故障日志分级
- 引入自动化回归测试（串口协议与门控逻辑）
- 增加版本变更记录（CHANGELOG）
