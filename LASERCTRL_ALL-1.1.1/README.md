## 1. 项目概述

本项目是一个基于 STM32F103RCT6 微控制器的**三通道半导体激光器驱动控制系统**。系统通过内部 DAC、外部 I2C DAC（MCP4725）和 ADC 反馈回路，实现对三台激光器的独立恒流驱动与实时监控。

### 1.1 核心功能

| 功能 | 说明 |
|------|------|
| 独立控制 | 通过 UART 串口指令独立调节每台激光器的驱动电流 |
| 优先级联锁 | 激光器间存在严格的级联使能关系，防止误操作 |
| 温度保护 | 实时监测激光器温度就绪信号，未就绪时禁止启动 |
| 反馈监控 | 4 通道 ADC + DMA 持续采集各激光器的输出电压和电流 |
| 混合 DAC | Laser1/2 使用 STM32 内部 DAC，Laser3 使用外部 MCP4725（I2C） |

### 1.2 适用场景

- 科研实验中的多波长激光器协同控制
- 光纤激光器泵浦源驱动
- 需要严格顺序上电的激光器阵列

## 2. 系统架构设计

### 2.1 优先链设计

系统采用**级联优先链（Cascade Priority Chain）**架构，确保激光器按序启动：

```
Laser1 ──→ Laser2 ──→ Laser3
(最高)     (中级)     (最低)
```

**规则**:
- **Laser1**：仅需自身温度就绪即可工作
- **Laser2**：需要 **Laser1 已就绪 + 自身温度就绪** 两者同时满足
- **Laser3**：需要 **Laser1 已就绪 + Laser2 已就绪 + 自身温度就绪** 三者同时满足

**设计意图**: 激光器 1 为基础泵浦源，激光器 2 依赖激光器 1 的输出，激光器 3 依赖前两级。任何前级掉线都会自动禁用后级，保证系统安全。

### 2.2 控制环路

每个激光器都采用**开环设定 + 闭环反馈**的控制模式：

```
UART 指令 → DAC 设定值 → 驱动电路 → 激光器
                              ↓
                        ADC 采样反馈
                              ↓
                    UART 输出实际值（电压/电流）
```

- **设定路径**: UART 指令 → 调整 DAC 值 → 通过模拟电路转为驱动电流
- **反馈路径**: 采样电阻电压 → ADC 采集 → DMA 传输 → 换算为实际电流/电压
- **监控输出**: 每次调节后通过串口打印设定值和实测值

## 3. 硬件配置详解

### 3.1 引脚分配总表

| 引脚 | 功能 | 方向 | 说明 |
|------|------|------|------|
| **PA0** | ADC1_IN0 | 模拟输入 | Laser1 输出电压采样 |
| **PA1** | ADC1_IN1 | 模拟输入 | Laser2 输出电压采样 |
| **PA2** | USART2_TX | AF推挽 | 串口发送（115200bps） |
| **PA3** | USART2_RX | 浮空输入 | 串口接收 |
| **PA4** | DAC_OUT1 | 模拟输出 | Laser1 驱动电压 |
| **PA5** | DAC_OUT2 | 模拟输出 | Laser2 驱动电压 |
| **PA6** | ADC1_IN6 | 模拟输入 | Laser3 输出电压采样 |
| **PA7** | ADC1_IN7 | 模拟输入 | Laser3 输出电流采样 |
| **PA13** | SWDIO | — | 调试接口（保留） |
| **PA14** | SWCLK | — | 调试接口（保留） |
| **PA15** | GPIO_Output | 推挽输出 | Laser2 使能控制 |
| **PB6** | I2C1_SCL | 开漏AF | MCP4725 时钟线 |
| **PB7** | I2C1_SDA | 开漏AF | MCP4725 数据线 |
| **PB12** | GPIO_Output | 推挽输出 | Laser1 使能控制 |
| **PB13** | GPIO_Input | 下拉输入 | Laser1 温度就绪检测 |
| **PB14** | GPIO_Input | 下拉输入 | Laser2 温度就绪检测 |
| **PB15** | GPIO_Input | 下拉输入 | Laser3 温度就绪检测（当前代码已屏蔽） |
| **PC4** | GPIO_Output | 推挽输出 | Laser3 使能控制 |
| **PD0** | OSC_IN | — | 外部 8MHz 晶振 |
| **PD1** | OSC_OUT | — | 外部 8MHz 晶振 |

### 3.2 使能引脚逻辑

| 激光器 | 使能引脚 | 高电平含义 | 使能条件 |
|--------|---------|-----------|----------|
| Laser1 | PB12 | 允许工作 | 自身温度就绪 |
| Laser2 | PA15 | 允许工作 | Laser1 就绪 + 自身温度就绪 |
| Laser3 | PC4 | 允许工作 | Laser1/2 就绪 + 自身温度就绪 |

所有使能引脚默认下拉，初始状态为**全部禁用**。

### 3.3 温度检测引脚逻辑

| 激光器 | 检测引脚 | 高电平含义 |
|--------|---------|-----------|
| Laser1 | PB13 | 温度已就绪 |
| Laser2 | PB14 | 温度已就绪 |
| Laser3 | PB15 | 温度已就绪（当前强制为就绪） |

检测引脚使用 200ms 消抖，状态变化时自动更新所有后级激光器的使能状态。

### 3.4 ADC 通道配置

ADC1 使用 **4 通道规则组扫描 + DMA 循环传输**：

| 通道 | ADC引脚 | 采样顺序 | 采样周期 | 用途 |
|------|---------|----------|----------|------|
| CH0 | PA0 (ADC1_IN0) | Rank 1 | 55.5 Cycles | Laser1 输出采样 |
| CH1 | PA1 (ADC1_IN1) | Rank 2 | 55.5 Cycles | Laser2 输出采样 |
| CH2 | PA6 (ADC1_IN6) | Rank 3 | 55.5 Cycles | Laser3 电压采样 |
| CH3 | PA7 (ADC1_IN7) | Rank 4 | 55.5 Cycles | Laser3 电流采样 |

- ADC 时钟: 12MHz (PCLK2/6 = 72MHz/6)
- DMA: DMA1_Channel1，循环模式，半字对齐

### 3.5 时钟配置

| 时钟域 | 频率 |
|--------|------|
| HSE | 8MHz (外部晶振) |
| PLL 倍频 | ×9 |
| SYSCLK | 72MHz |
| HCLK | 72MHz |
| APB1 (PCLK1) | 36MHz |
| APB2 (PCLK2) | 72MHz |
| ADC CLK | 12MHz (PCLK2/6) |

## 4. 软件设计原理

### 4.1 主循环结构

```
main()
  ├── 初始化阶段
  │   ├── HAL_Init()
  │   ├── SystemClock_Config()     // 72MHz
  │   ├── MX_GPIO_Init()           // 引脚配置
  │   ├── MX_DMA_Init()            // DMA 时钟 + NVIC
  │   ├── MX_ADC1_Init()           // ADC 4通道 + DMA
  │   ├── MX_DAC_Init()            // DAC 双通道
  │   ├── MX_I2C1_Init()           // I2C1 100kHz
  │   ├── MX_USART2_UART_Init()    // USART2 115200
  │   ├── 启动外设（DAC、ADC-DMA）
  │   ├── MCP4725 初始化为 0V
  │   └── 首次 ADC 采样 + 使能状态刷新
  │
  └── 主循环（无限循环）
      ├── Laser1 温度检测（200ms 消抖）
      ├── Laser2 温度检测（200ms 消抖）
      ├── UART 单字节接收（100ms 超时）
      └── 指令解析与执行
          ├── 优先级校验
          ├── DAC 调整（内部/MCP4725）
          ├── 等待稳定 + ADC 刷新
          └── 计算并打印实际值
```

### 4.2 关键算法说明

#### 4.2.1 Laser1/Laser2 DAC 换算

```
设定电压:  V_dac = DAC_Value × 3.3V / 4096
设定电流:  I_set = V_dac / 2.5Ω
实际电压:  V_out = ADC_Value × 3.3V / 4096
实际电流:  I_mon = V_out / 2.5Ω
```

其中 2.5Ω 为采样电阻值。

#### 4.2.2 Laser3 电压换算（PA6，带映射）

由于 Laser3 前端信号调理电路的存在，PA6 的 ADC 电压与实际输出电压之间存在线性映射：

```
V_adc  = ADC_Value × 3.3V / 4096
V_实际 = 2.0V + (V_adc - 0V) × (3.3V - 2.0V) / (3.26V - 0V)
```

即 ADC 输入 0~3.26V 映射到实际 2.0V~3.3V。

#### 4.2.3 Laser3 电流换算（PA7，带映射）

类似地，PA7 的电流采样也经过线性映射：

```
V_adc   = ADC_Value × 3.3V / 4096
I_实际  = 0.8A + (V_adc - 0V) × (10A - 0.8A) / (2.71V - 0V)
```

即 ADC 输入 0~2.71V 映射到实际 0.8A~10A。

#### 4.2.4 MCP4725 驱动（I2C 外部 DAC）

Laser3 使用的外部 MCP4725 是一款 12 位 I2C DAC：

```
I2C 地址: 0xC0 (7位地址 0x62 << 1)
写入格式: [0x40] [D11-D4] [D3-D0 << 4]
模式:     Fast Write（仅更新 DAC 寄存器，不掉电）
```

### 4.3 温度检测消抖

每个激光器的温度就绪信号通过 GPIO 读取，使用 200ms 消抖周期（`TEMP_DEBOUNCE_MS`）避免误触发。消抖逻辑仅在状态**发生改变**时才触发后续的使能状态更新和串口输出，避免无效的重复操作。

### 4.4 ADC 更新策略

`UpdateADCValues()` 函数采用"停止-清零-重启-等待"的策略强制刷新 ADC 值：

1. 停止当前 DMA 传输
2. 清零 ADC 缓冲区
3. 重新启动 DMA 传输
4. 等待 50ms 确保至少完成一次扫描转换

这确保了每次 DAC 调整后获取的是最新的测量值。

### 4.5 串口输出

系统通过 `printf` 将调试信息输出到 USART2（重定向 `fputc`）。输出内容包括：

- 系统启动提示
- 温度状态变化
- 每次指令执行后的 DAC 设定值 / 实际电压 / 实际电流
- ADC 原始数据（DMA 回调自动打印）
- 无效指令警告
- 优先级阻止原因

## 5. 通信协议（UART 指令集）

### 5.1 接口参数

| 参数 | 值 |
|------|-----|
| 波特率 | **115200 bps** |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验位 | 无 |
| 流控 | 无 |

### 5.2 指令表

指令为**单字节 ASCII 字符**，范围 `0` ~ `9`：

| 指令 | 目标激光器 | 操作 | 步长 | DAC 范围 |
|------|-----------|------|------|----------|
| **`0`** | Laser1 | 大步减小 | -31 | [0, 3103] |
| **`1`** | Laser1 | 大步增大 | +31 | [0, 3103] |
| **`2`** | Laser1 | 小步减小 | -3 | [0, 3103] |
| **`3`** | Laser1 | 小步增大 | +3 | [0, 3103] |
| **`4`** | Laser2 | 大步增大 | +31 | [0, 3103] |
| **`5`** | Laser2 | 大步减小 | -31 | [0, 3103] |
| **`6`** | Laser2 | 小步增大 | +3 | [0, 3103] |
| **`7`** | Laser2 | 小步减小 | -3 | [0, 3103] |
| **`8`** | Laser3 | 增大 | +20 | [0, 1861] |
| **`9`** | Laser3 | 减小 | -20 | [0, 1861] |

### 5.3 步长设计原理

- **Laser1/2 大步 (31)**: 对应 12 位 DAC 的约 0.76% 满量程变化，适合快速粗调
- **Laser1/2 小步 (3)**: 约 0.073% 满量程，用于精密微调
- **Laser3 (±20)**: MCP4725 也是 12 位，范围限制为 1861（约 45% 满量程），保护激光器不过流

### 5.4 指令响应示例

```
// 增大 Laser1 一大步（发送 '1'）
Laser1: DAC=3131, 设定电流=1.005A, 设定电压=2.522V, 监测电流=0.998A, 输出电压=2.495V

// Laser2 温度未就绪时尝试操作（发送 '5'）
错误: Laser2温度未就绪,无法执行指令

// Laser1 未就绪时尝试操作 Laser2（发送 '4'）
错误: Laser1未就绪,无法操作Laser2
```

### 5.5 错误处理

| 情况 | 输出信息 |
|------|---------|
| 无效字符 | `无效指令（仅支持0-9）` |
| Laser1 未就绪 | `错误: Laser1温度未就绪,无法执行指令` |
| Laser2 未就绪 | `错误: Laser2温度未就绪,无法执行指令` |
| Laser1 未就绪使 Laser2 不可用 | `错误: Laser1未就绪,无法操作Laser2` |
| 超时无数据 | `uart_cmd = 0`（跳过本轮） |

## 6. 编译与烧录

### 6.1 前置条件

- **MDK-ARM (Keil uVision)** V5.32 或更高
- **STM32Cube FW_F1** V1.8.6（HAL 库）
- **STM32F103RCT6** 目标板
- **ST-Link / J-Link** 调试器

### 6.2 编译步骤

1. 用 Keil uVision 打开 `MDK-ARM/LaserCtrl_all.uvprojx`
2. 确认 Project → Options → Target 中芯片型号为 `STM32F103RC`
3. 确认 C/C++ 选项卡中 Include Paths 包含：
   - `Core/Inc`
   - `Drivers/STM32F1xx_HAL_Driver/Inc`
   - `Drivers/CMSIS/Device/ST/STM32F1xx/Include`
   - `Drivers/CMSIS/Include`
4. 在 Define 中添加：`USE_HAL_DRIVER,STM32F103xE`
5. 按 F7 编译（Build）

### 6.3 烧录

- 使用 ST-Link 连接 SWDIO (PA13) 和 SWCLK (PA14)
- Keil 中按 F8（Download）烧录
- 或使用 STM32CubeProgrammer 烧录生成的 HEX 文件

### 6.4 调试

- PA13 / PA14 已配置为 Serial Wire 调试模式
- 串口调试：连接 PA2 (TX) / PA3 (RX)，波特率 115200，可查看实时输出

## 7. 使用说明

### 7.1 上电流程

1. **连接硬件**: 确保所有电源、激光器、温度传感器正确连接
2. **上电**: 系统自动初始化，串口输出欢迎信息
3. **等待温度就绪**: 观察串口输出，确认 Laser1 和 Laser2 温度就绪
   ```
   Laser1: 温度就绪,已使能
   Laser2: 温度就绪
   ```
4. **发送指令**: 使用串口助手（如 SSCOM、PuTTY）发送单字符指令 `0`~`9`

### 7.2 典型操作流程

```
// 1. 确认系统启动
系统初始化完成，等待指令...

// 2. 等待温度就绪（自动打印）
Laser1: 温度就绪,已使能
Laser2: 温度就绪
Laser3: 温度就绪

// 3. 逐步增大 Laser1 驱动电流
发送: 1  // 大步增大
发送: 1  // 继续增大到目标值
发送: 3  // 小步微调

// 4. 启动 Laser2（Laser1 必须已就绪）
发送: 4  // 大步增大

// 5. 启动 Laser3（Laser1 和 Laser2 必须已就绪）
发送: 8  // 增大 Laser3

// 6. 关机时逐步减小
发送: 9 → 9 → 9 ...  // 减小 Laser3 到 0
发送: 5 → 5 → 5 ...  // 减小 Laser2 到 0
发送: 0 → 0 → 0 ...  // 减小 Laser1 到 0
```

### 7.3 注意事项

1. **严格遵循关机顺序**: 先关 Laser3 → Laser2 → Laser1
2. **温度就绪前禁止操作**: 即使用户发送指令也会被优先级校验拦截
3. **Laser3 温度检测已屏蔽**: 当前版本 Laser3 的温度检测被强制设为"就绪"，硬件修复后需取消注释恢复检测
4. **大范围调节使用大步**: 先粗调（31/20 步）再精调（3 步）
5. **观察反馈值**: 每次指令后系统会返回设定值和测量值，两者应基本一致；偏差过大说明硬件故障

## 8. 自定义修改指南

### 8.1 修改步长

在 [main.c](Core/Src/main.c) 中找到各 `case` 分支中的步长值：

```c
// Laser1 大步 (±31)
case '0': DAC_Value1 = (DAC_Value1 >= 31) ? (DAC_Value1 - 31) : 0;
case '1': DAC_Value1 = (DAC_Value1 <= 3103) ? (DAC_Value1 + 31) : 3103;

// Laser3 (±20)
case '8': DAC_Value3 = (DAC_Value3 <= 1861) ? (DAC_Value3 + 20) : 1861;
```

修改对应数字即可。

### 8.2 修改 DAC 上限

```c
// Laser1/2 上限 3103（约 2.5V）
// 修改对应位置值 → 改为你需要的上限

// Laser3 上限 1861（约 1.5V，受限于 MCP4725 后级电路）
// 修改对应位置值 → 改为你需要的上限（最大 4095）
```

### 8.3 恢复 Laser3 温度检测

在 [main.c](Core/Src/main.c) 中，找到被注释的 Laser3 温度检测代码段（约第 278-294 行），取消注释：

```c
// 取消下面这段注释即可恢复 Laser3 温度检测
if (HAL_GetTick() - last_temp_check3 >= TEMP_DEBOUNCE_MS)
{
    last_temp_check3 = HAL_GetTick();
    uint8_t temp_status3 = HAL_GPIO_ReadPin(GPIOB, GPIO_PIN_15);
    // ...
}
```

同时将 `temp_status_prev3` 初始值改为 `0`。

### 8.4 修改采样电阻值

在 [main.c](Core/Src/main.c) 中：
```c
Ic_value1 = Input_Vcc1 / 2.5f;  // 将 2.5 改为实际采样电阻值
Im_value1 = ADC_Value[0] * 3.3f / 4096.0f / 2.5f;
```

### 8.5 通过 CubeMX 修改硬件配置

项目包含 `.ioc` 文件，可用 STM32CubeMX 打开并重新生成初始化代码。生成后用户代码区域（`USER CODE BEGIN/END` 之间的内容）将被保留。

## 附录 B: 常见问题

**Q: 发送指令后无响应？**  
A: 检查串口波特率是否为 115200，TX/RX 连接是否正确（PA2→对方RX, PA3→对方TX）。

**Q: 提示"温度未就绪"但硬件已就绪？**  
A: 检测 PB13/PB14 引脚是否为高电平。引脚默认下拉，确保外部信号能驱动到高电平。

**Q: 实测电流与设定电流偏差较大？**  
A: 检查 `main.c` 中采样电阻值是否与实际硬件一致（默认 2.5Ω）。

**Q: Laser3 无法调节？**  
A: 检查 I2C 连接（PB6/PB7），确认 MCP4725 的 I2C 地址是否为 0x60（7位）。

**Q: 如何修改波特率？**  
A: 在 STM32CubeMX 中打开 `.ioc` 文件，修改 USART2 的波特率后重新生成代码，或在 `usart.c` 中直接修改 `huart2.Init.BaudRate`。
